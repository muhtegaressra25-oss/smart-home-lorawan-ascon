# Implementasi ASCON-AEAD128 pada Smart Home Berbasis LoRaWAN

Repository ini berisi kode program skripsi implementasi ASCON-AEAD128 pada sistem smart home berbasis LoRaWAN.

## Perangkat
- Heltec WiFi LoRa 32 V3
- Raspberry Pi 4 + WM1302
- ChirpStack
- Mini PC Backend
- Node-RED

## Pengujian
Pengujian dilakukan pada kondisi LOS dan NLOS, tanpa dan dengan ASCON-AEAD128.

## Keamanan
Kunci enkripsi dan kredensial jaringan tidak dipublikasikan.
